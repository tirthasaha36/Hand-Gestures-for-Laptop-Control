# Next Steps After Training Gestures

## Steps to Complete:

1. [ ] Train the machine learning model using gesture_ml.py
2. [ ] Test the trained model in real-time
3. [ ] (Optional) Enable system control mappings in main.py
4. [ ] Run main.py for full gesture control system

## Commands to run:
- `python gesture_ml.py` (choose option 1 to train model)
- `python gesture_ml.py` (choose option 2 to test in real-time)
- `python main.py` (for full system with gesture recognition)

## Notes:
- Make sure you have collected sufficient gesture data (at least 2-3 gestures with 30 samples each)
- The model will be saved to `models/gesture_model.pkl`
- System control features are currently commented out in main.py
